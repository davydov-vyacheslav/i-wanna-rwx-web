# Design

- `design-system.md` is the source of truth: principles, tokens (values in `frontend/src/theme.css`), iOS-native-feel rules, components, states, i18n.
- `INTERACTIONS.md`: user flows and edge cases.
- `prototypes/index.html` opens the clickable prototype (`app.html`): every screen and state in light, dark, ru, uk. No build, works offline; reference only, do not reuse its CSS.

Business rules live in `docs/openspec/specs/`. Open design items: `docs/TODO.md`.
