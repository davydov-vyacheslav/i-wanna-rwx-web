# Tasks: media-core
Prerequisite: Phase 2 done (the `SettingsScreen` is in the tree and rendered by `App`); `identity-github-oauth` B1-B3 and B6 merged (`CurrentUserProvider`, test kit, `/me`) and F1-F2 for the frontend (API plumbing, per-user naming). The contract and V001 no longer carry the create request, the media fields or the media error responses (removed in the Phase 2 cleanup, 2026-11-18): the first backend task restores them from `refs/shelf/pre-cleanup`. Tracks are otherwise independent; the frontend develops against generated types plus an injected fetch. The frontend is online-first (TanStack Query over the API); Dexie cache, outbox, offline drafts/banners, pending-sync dots and Undo-through-outbox belong to `offline-sync` (Offline/PWA phase).
